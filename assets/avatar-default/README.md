# assets/avatar-default - the set Kairos ships with

Seven faces in one outfit, six gestures, and the reference they were all grown from.
`harness/control/avatar_seed.py` copies whatever is missing into `var/room/avatar/` on
gateway boot, so a fresh clone has a face instead of the fallback SVG.

**It is a starting point, not a fixture.** Nothing here is privileged: the seeder only
ever fills gaps, never overwrites, and never re-adds anything you delete or hide. Point
`_reference.png` and `character.txt` at your own character and every generation from then
on is yours - see [`docs/SETUP.md`](../../docs/SETUP.md) and
[`docs/AVATAR-PIPELINE.md`](../../docs/AVATAR-PIPELINE.md).

| | |
|---|---|
| `<face>/t0/still.png` + `loop.webm` | the grid cell for each of the seven faces `MOODS` maps onto, in the default outfit |
| `looks/d-*.png` + `.webm` | six gestures - laugh, think, lean, glance, blush, wave |
| `wants.jsonl` | the six gesture rows, already `made`, ids prefixed `d-` so your own wants (`w001`...) can never collide |
| `_reference.png` | the one identity source every image above was edited from |
| `character.txt` | the prose half of that identity - **a template, meant to be replaced** |
| `SET.json` | what this set is and where each file came from |

The `.json` receipt beside each asset carries the model, the reference hash and the
timestamp. **The prompts are not included** - the images ship, the writing that made them
does not.

Generated by `tools/kairos_default_set.py` in the source repo. Do not hand-edit; re-run it.
